# 📘 RESUMO — IF, ELSE e SELEÇÃO (C++)

## 🧠 IDEIA GERAL
Programas tomam decisões com base em condições.

👉 Isso é feito com **estruturas de seleção**:
- if (se)
- if...else (se / senão)
- if...else if...else (vários casos)
- operador ternário (?)

---

## 🔹 PSEUDOCÓDIGO
Antes de programar, podemos descrever o passo a passo em linguagem simples.

Exemplo:
- Ler dois números
- Multiplicar
- Mostrar resultado

➡️ Serve pra organizar o raciocínio antes do código.

---

## 🔹 PROGRAMAÇÃO ESTRUTURADA
Todo programa pode ser feito com apenas 3 estruturas:

1. Sequência (linha a linha)
2. Seleção (decisão)
3. Repetição (loops)

⚠️ Evitar `goto` (má prática)

---

## 🔹 IF (SELEÇÃO SIMPLES)

Executa algo **somente se a condição for verdadeira**.

```cpp
if(val > 12)
    cout << "Maior que 12";
```

✔️ Se for verdadeiro → executa  
❌ Se for falso → não faz nada  

---

## 🔹 IF...ELSE (SELEÇÃO DUPLA)

Escolhe entre **duas possibilidades**.

```cpp
if(val > 12)
    cout << "Maior que 12";
else
    cout << "Menor que 12";
```

✔️ Sempre executa **uma das opções**

---

## 🔹 IF...ELSE IF...ELSE (MÚLTIPLOS CASOS)

Usado quando há **várias condições**.

```cpp
if(temp > 40)
    cout << "Muito calor";
else if(temp > 30)
    cout << "Calor";
else if(temp > 20)
    cout << "Temperatura ok";
else if(temp > 10)
    cout << "Frio";
else
    cout << "Muito frio";
```

👉 O programa testa **de cima pra baixo**
👉 Executa o **primeiro que for verdadeiro**

---

## 🔹 OPERADOR TERNÁRIO (?)

Forma curta do if...else.

```cpp
cout << (val > 12 ? "Maior" : "Menor");
```

Estrutura:
```
(condição) ? valor_se_verdadeiro : valor_se_falso
```

✔️ Mais compacto  
❗ Usar com moderação (pode dificultar leitura)

---

## 🔹 EXERCÍCIO (CLASSIFICAÇÃO DE NOTA)

Entrada: nota de 0 a 100

- 90–100 → A
- 80–89 → B
- 70–79 → C
- < 70 → REPROVADO
- fora do intervalo → INVÁLIDO

👉 Exige uso de múltiplos if...else

---

## ⚡ RESUMO FINAL (PRA MEMORIZAR)

- `if` → executa se for verdadeiro
- `if...else` → escolhe entre 2 caminhos
- `else if` → vários caminhos
- `? :` → versão compacta do if...else
- Ordem importa → o primeiro verdadeiro é executado

---

## 🎯 DICA PRÁTICA
Sempre pense assim:

👉 "Se isso acontecer, faço isso. Senão, faço aquilo."

Isso é literalmente o `if...else`.
